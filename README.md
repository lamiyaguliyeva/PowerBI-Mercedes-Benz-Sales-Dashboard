# 🚗 Mercedes-Benz Sales Dashboard

## 📌 Project Overview
This project is an interactive Power BI dashboard developed to analyze Mercedes-Benz sales data. The dashboard helps visualize sales performance, regional distribution, and model trends through interactive charts and KPIs.

---

## 🎯 Objectives
- Analyze sales performance
- Compare regional sales
- Evaluate vehicle model performance
- Identify sales trends

---

## 📊 Dashboard Pages

### 🌍 Geographic Analysis
- Regional sales distribution
- Interactive map visualization

### 📈 Sales & Performance Analysis
- Revenue trends
- KPI cards
- Sales comparison

### 🚘 Model & Category Trends
- Vehicle model analysis
- Category comparison
- Trend visualization

---

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

---

## ✨ Features
- Interactive dashboard
- KPI cards
- Dynamic filters (Slicers)
- Drill-down analysis
